# 拖入自动编号搬运工具（Drag & Drop Auto-Number Import）

把下载下来的一堆视频/文件拖进命令行窗口，按拖入顺序自动重命名成 `1、2、3……` 并移动（或复制）到你选定的文件夹。

纯本地 PowerShell 脚本：**不联网、不上传、不下载**，只对你自己拖进来的文件做改名和移动/复制，绝不覆盖目标文件夹里已存在的文件。

## 文件说明

| 文件 | 说明 |
|---|---|
| `Run.bat` | 双击启动（只需要点这一个文件） |
| `AutoNumberImport.ps1` | 程序本体，不要改名、不要单独移动 |
| `README.md` | 本说明 |

两个文件必须放在同一个文件夹里，整个文件夹放在哪都行（桌面、D 盘、U 盘都可以）。

## 快速开始

1. 双击 `Run.bat`。
2. 第一次运行如果弹出「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
   （这是系统对 `.ps1` 脚本的常规提示，可以放心。）
3. 按窗口提示操作：

   第 1 步：把**目标文件夹**拖进窗口（直接回车 = 沿用上次的文件夹）
   第 2 步：起始编号（直接回车 = 自动，取目标文件夹里已有的最大纯数字文件名 + 1）
   第 3 步：导入方式（`1` 移动 / `2` 复制，回车沿用上次）
   第 4 步：把视频**拖进窗口**，自动显示重命名预览，输入 `go` 回车开始
   第 5 步：完成，回车继续下一批 / `o` 打开目标文件夹 / `q` 退出

   拖文件进来**不需要按回车**；只有手动打字输入的命令才需要回车。

## 命令速查（第 4 步）

| 命令 | 作用 |
|---|---|
| `go`（或 `开始` / `s` / `g`） | 开始导入 |
| `c` | 清空当前列表，重新拖 |
| `b` | 返回上一步，重新选文件夹 |
| `q` | 退出（不导入） |
| `l` | 刷新显示列表 |
| 直接回车 | 只是刷新列表 |

## 关于顺序

- 一个一个拖：顺序完全按拖入先后，最准确。
- 一次拖多个：Windows 一般按文件名顺序塞进来；想完全控制就分批拖。
- 拖文件夹：按文件名顺序把该文件夹里的文件全部加入。
- 重复拖同一个文件：自动忽略。
- 扩展名原样保留（mp4 还是 mp4，mov 还是 mov，混着也行）。

## 补零（01、02、03）

编辑 `%APPDATA%\AutoNumberImport\config.json`，把 `"PadWidth": 0` 改成 `2`（两位）或 `3`（三位）。

## 配置与日志

都在 `%APPDATA%\AutoNumberImport\`：

- `导入记录.log` — 每次导入的明细（时间、原路径、新路径、成功/失败原因）
- `config.json` — 记住的目标文件夹 / 方式 / 补零设置

删掉整个 `AutoNumberImport` 文件夹 = 清除所有记忆和日志。

## 常见问题

- **不会覆盖已有文件**：自动编号从已有最大编号 +1 开始；手动指定的编号被占用时自动顺延。
- **导入失败**：多半是文件还被播放器/网盘等程序占用，或文件已被删除；失败文件保留在原来的位置，重新拖进来即可。原因记录在日志里。
- **路径带空格**：手动输入时用双引号括起来；直接拖动最省事。
- **中途终止**：`Ctrl+C` 或输入 `q` 退出；已导入的文件不回滚，剩下的留在原位置。
- **跨盘移动**：正常支持。
